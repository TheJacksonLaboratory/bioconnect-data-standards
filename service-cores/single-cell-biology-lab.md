# Single Cell Biology Lab Data Standards

## Sample Sheets
The Single Cell Biology Lab uses sample sheets that include the columns listed below. Notes captured for specific columns are preserved under each field.

The columns are as follows:

- **Sample ID**
  - We will want to add `Sample ID` and `Source ID`

- **Experiment Condition**
  - Recommend two columns: `Treatment` and `Condition`.
  - Customers do not usually understand the point of the column.
  - Like Protein Sciences, this should only be about `Treatment`.

- **Disease Type**
  - This could be needed for sample handling, spatial analysis, etc.
  - Take the same approach by 1) populating with existing terms and 2) having an `Other` column.
  - NCIT is a good ontology to use.

- **Cell Type**
  - Use the same strategy as above.

- **Preservation Method**
  - Use the same strategy as above.

- **Tissue Type**
  - We are seeing cell lines in the tissue column.
  - This would also follow the same strategy.

- **Sample Type**
  - Use the same strategy as above.
