# Growing a FAIR Data Ecosystem

## Goals, priorities, and path to adoption

As part of JAX’s initiative to ensure all data produced is **FAIR** (*Findable, Accessible, Interoperable, and Reusable*), this group aims to pilot a process to store data generated through Scientific Services in an easily accessible and reusable fashion for the JAX research community and collaborators. To begin to achieve this goal, **BioConnect** has been developed as the entry point for indexing data produced by Scientific Services for JAX researchers and the associated metadata. An efficient workflow to ingest data generated by both customers and Scientific Services into BioConnect is needed. 

To achieve this, we propose a pilot focused on four initial services: Protein Sciences, Cellular Engineering, Genomic Technologies, and Single Cell Biology.

Phase One will focus on developing a structured interface with Scientific Services for the customer to provide relevant metadata about submitted samples. Additionally, part of the pilot will be to build up BioConnect to receive raw data and associated metadata from Scientific Services that the customer can access. Pending the outcome of Phase One, a second phase can focus on integrating BioConnect with iLabs and L7 ESP. 

## Phase One Goal

1. Import Scientific Services generated data and customer metadata into BioConnect
   - All data entered into BioConnect is FAIR
   - Determine the potential burden of metadata entry for customers
   - Identify potential customers and customer datasets that can be used to test ingest processes
   - Gather feedback from Services about usability and identify operational constraints 

## Stretch Goal

1. Streamline data gathering for both services and customers
   - Reduce redundant data entry and standardize common terms
   - Standardize metadata collection
   - Connect projects that interact with multiple services

## Process for Developing and Adopting Service Workflows

For each Scientific Service core, we will use a common implementation process to design a routine workflow that works for staff and customers while supporting born-FAIR data practices:

1. **Discover the current workflow.** Gather input from service staff and customers to understand current practices, required metadata, pain points, and which parts of the workflow should remain unchanged.
2. **Define the target workflow.** Document the desired future-state process, including what data and metadata should be collected, when they should be collected, and how they should connect to assays, samples, and projects.
3. **Design the solution.** Develop a standards-based workflow and system design that fits the service’s operational needs while aligning with shared identifiers, metadata structures, and BioConnect integration requirements. Coordinate with the Data Standards Team.
4. **Prototype and review.** Build a lightweight prototype, review it with service staff, representative users, and the Data Standards Team to confirm that it supports both operational efficiency and FAIR data goals.
5. **Pilot and refine.** Test the workflow in practice, gather feedback, identify gaps, and iteratively refine the process, metadata model, and user experience.
6. **Adopt and operationalize.** Finalize the workflow, train participants, and put the solution into routine use as the standard approach for that service.
7. **Monitor and improve.** Evaluate adoption, data quality, and usability over time, and make incremental improvements as service needs and research workflows evolve. 

This phased approach will help ensure that each service integration is practical, standards-aligned, and sustainable, while contributing to a broader FAIR data ecosystem across JAX. 

## BioConnect

BioConnect is JAX’s centralized platform for organizing, indexing, and connecting research data and metadata so they can be more easily discovered, accessed, and reused. It serves as a bridge between scientific services, researchers, and downstream analysis by bringing together datasets, sample information, and project context in a structured, standards-aligned way that supports FAIR data practices across the research community.
